1. Overview & flow

DocMaster AI uploads PDF or PPTX files, extracts text and tables, and generates reports, dev feature lists, or test cases based on your selection.

Flow

  1. Before start: Register your LLM API key in [Key settings] (top right).
  2. Step 1: Upload a PDF or PPTX on the main screen. The server extracts and converts to markdown.
  3. Step 2: Choose document type (planning report / dev features / test cases). For reports, select executive or team style and HTML format, then click [Generate report].
  4. Custom questions (optional): For planning reports, after the first draft you may see 2–3 multiple-choice questions. Choose options and click [Apply & continue] to refine, or [Skip] to generate HTML as-is.
  5. Result: View the report in the popup and download HTML or refined markdown.

2. Before you start (Key setup)

Report generation uses external LLM APIs (OpenAI, Anthropic, Google). Enter your API key and select an LLM in [Key settings] (top right).

[ Screenshot: Key settings ]
[ Screenshot: API key modal ]

API keys are stored only in the browser (Local Storage). Only extracted text is sent to the selected LLM when generating reports.

3. Step 1 — Upload & extract

Drag and drop or click to select a PDF or PPTX in the upload area. Supported formats: PDF, PPTX only. Files are deleted from the server after extraction.

[ Screenshot: Upload area ]

4. Step 2 — Document type & report generation

After extraction you see Step 1 complete, a preview, and three cards: Planning report, Dev features, Test cases. Choose report style (Executive / Team) and HTML format, then click [Generate report] or [Generate].

[ Screenshot: Cards ]
[ Screenshot: Report options ]

HTML formats: Proposal style, Presentation style, Preformat. Refined md is reused when you only change the HTML format.

4.1 Custom questions (intent)

For planning reports, after the first draft you may see 2–3 multiple-choice questions. Pick options and [Apply & continue] to refine, or [Skip] to generate HTML as-is.

[ Screenshot: Custom questions ]

5. View & download report

Click [View report] to open the HTML in a popup. Mermaid diagrams in the report are rendered. You can download HTML or refined .md.

[ Screenshot: Report viewer ]

6. Prompt editing

On each card, [Edit prompt] opens a modal to edit prompts for that type. Saved to Local Storage.

[ Screenshot: Prompt modal ]

7. Template management

[Template management] (top right) lets you view and edit HTML templates (proposal, presentation, preformat, test cases, dev features).

[ Screenshot: Template modal ]

8. Tips

  • Register API key and test connection before uploading.
  • Executive = short summary; Team = detailed with owners and dates.
  • High quality = extra review rounds (more time and cost).
  • Same extraction + same report type: change only HTML format to reuse refined md.
  • Use [Edit prompt] to customize terminology and required sections.
