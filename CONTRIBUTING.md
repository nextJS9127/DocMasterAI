# Contributing to DocMaster AI

Thanks for your interest in contributing. Below are simple guidelines for issues and pull requests.

## Share your improvements / 개선 사항 공유

**이 저장소를 포크하거나 가져다 사용하시다가 더 좋게 개선하셨다면, 꼭 함께 공유해 주세요.**

If you use this project (as-is or forked) and make it better—new features, fixes, or ideas—please share them so others can benefit too.

- **개선 사항·아이디어 공유**: [Issues](https://github.com/nextJS9127/DocMasterAI/issues) or [Discussions](https://github.com/nextJS9127/DocMasterAI/discussions)
- **코드 반영**: [Pull Requests](https://github.com/nextJS9127/DocMasterAI/pulls)

---

## Reporting issues

- **Search** existing [Issues](https://github.com/nextJS9127/DocMasterAI/issues) first to avoid duplicates.
- Use a **clear title** and describe:
  - What you did (steps or environment)
  - What you expected
  - What actually happened (screenshots or logs if helpful)
- Mention OS, Node/Python versions, and whether you use the web app or the VS Code extension when relevant.

## Pull requests

- **Open an issue** first for larger changes so we can align on the approach.
- **Fork** the repo, create a branch from `main`, and make your changes.
- **Keep changes focused** (one feature/fix per PR when possible).
- **Test** locally (frontend: `docmaster-web`, backend: `docmaster-backend`) before submitting.
- In the PR description, briefly explain what changed and why.

## Code style

- **Backend (Python)**: Follow common PEP 8 style; type hints welcome.
- **Frontend (React/TypeScript)**: Match existing style; use the project’s linter/formatting.

## Questions

Open a [Discussion](https://github.com/nextJS9127/DocMasterAI/discussions) or an Issue with the "question" label.

---

If you find DocMaster AI useful, consider giving the repo a **star** so others can discover it.
